# 足迹视频导出维护说明

导出保持纯浏览器、本机处理，不使用麦克风、系统音频或外部编码服务。默认完整行程和轻快旅行，原始足迹、照片与两首 WAV 不变。用户可明确选择无配乐。

优先录制 MP4 / H.264 / AAC；浏览器不支持时使用真正的 WebM / Opus，不改扩展名冒充 MP4。配乐音量为零、静音源、录制音轨丢失会阻止提供成品；录制时采样音量后的音频信号，完成后检查容器中的实际音轨。此检查不等于已由真人听音。

MediaRecorder 采用实时录制，生成用时接近片长，窗口必须留在前台。90 秒概览自动选取最多20站，保留起终点、选中事件完整文字与日期；移动仍经过中间真实记录坐标，片尾展示完整轨迹。较短行程不被强行拉长；若端点长文字本身超过90秒最低阅读时长，会以实际预计时长为准。完整行程始终保留全部站点。

视频为1280×720、30fps；柔化地形，只保留当前及近期地名的重点标签，减淡历史路线；网页交互地图不使用这组画面处理。新增测试在既有脚本及CI中执行。

字幕在编码画面中保留至少92像素底部余量；嵌入预览另显示当前日期、城市及完整事件文字。全屏使用contain，不裁切画面。地图脚本和样式带源码版本指纹，启动时固定720画布以避免旧HTML/旧缓存尺寸错配。MP4为推荐显式选择，不能录制时阻止生成并提示切换浏览器或主动选WebM；网页不会自动把WebM当成兼容MP4。浏览器原生可能输出分片MP4，实际元数据布局、视频/音频编码会被检查；未保证所有微信客户端预览。

视频字幕改为透明叠层：地图由440/720扩展至720/720，不再保留280像素不透明白底。白字、深色描边和轻阴影确保对比；日期28px、城市44px、事件34px，最多两行并分页保留全文，末行仍保留92像素底部安全区。地图城市标签避让字幕区域。微信头像为新增同源预设，与雨聊猫和本地自定义图片并存；原图保持不变，预览和导出共用256px圆形裁切标记。

字幕下移版（2026-10-24.5）：城市30px与日期/站序22px合并为同一行，事件26px，32px行距，距左右各32px。短说明两行、长说明最多三行，整体靠底，末行基线656，保留56px底部余量；常见播放器控件临时显示时可收起控件，网页预览仍提供下方完整说明。透明底、2.5px描边与轻阴影不变，长文依原文分页，不缩成一行截掉。头像与音频逻辑不变。
