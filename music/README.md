# 功能配乐素材

AI 辅助编写、Python 标准库程序合成，非真实乐器录音。不列入“我的作品”，不署名为用户作曲。没有使用第三方录音、采样包或现成曲谱；不宣称旋律绝对唯一。

生成器：`scripts/generate_music.py`（1.0），默认输出温柔回忆/轻快旅行的 WAV、可编辑音符 JSON、MIDI 和统计。`python scripts/generate_music.py --output 新目录`；编辑 JSON 后用 `--scores 包含gentle和travel子目录的归档目录 --output 另一个新目录`。目标目录必须尚不存在。MIDI 保留音符、和声、速度、乐器示意；精准音色/房间尾音应使用生成器复现。

网站只发布两份 WAV 与说明，不发布整套归档。音频为立体声 24 kHz/16-bit PCM，目标 RMS 约 -17.7 dBFS、峰值留有余量。合成尾音和房间延迟在周期边界连续，网站采用循环播放；录制时按视频时钟淡入/末尾淡出。网站默认关闭，首次主动播放后站内导航持续播放；硬刷新或外链离站后需重新播放；仅保存选曲/音量。视频设置独立，生成时暂停其他音频。


站内导航保留同一页头音频会话，各功能脚本在构建产物中封装为可清理的页面作用域。可直接访问、刷新和分享原 URL；不使用 iframe 或额外窗口。导航请求失败时退回常规页面加载，此时音乐会停止。关闭面板仅收起控制界面；暂停/停止为独立操作。后台省电、系统音频中断和浏览器限制仍可能中断声音。

地图上方的“地图 / 视频配乐”默认轻快旅行，独立于整站选曲并避免叠音。可选温柔回忆、无配乐、本地音频（不上传）；本地文件仅存于当前标签页内存中，限制 10 MB、0.5 秒至 5 分钟，刷新后需重选。较短音频循环，导出统一淡入淡出。用户须自行确认所选外部音乐的使用权限。两首既有 WAV、旋律数据与独立归档未改动。

本地回归：`node scripts/test_music.cjs`、`python scripts/test_site_navigation.py`；完整检查见 `.github/workflows/pages.yml`。浏览器验收还需检查同一会话跨模块持续、前进后退、页面清理、面板外点击及本地配乐真实视频音轨。
