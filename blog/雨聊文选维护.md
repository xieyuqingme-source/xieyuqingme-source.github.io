# 雨聊文选

独立入口 `/anthology/`；每篇为 `/anthology/<slug>/`。共用本仓库静态构建、品牌、导航及主题，不单独托管。文选不进入原创文章目录、文章 RSS 或英文翻译清单。

## 内容与来源

`anthology/content/` 是从用户明确指定的选文中复制的公开文本，5 个 Markdown、13 篇。按源文件保留 5 类：古代诗词曲 4 篇、古代散文 5 篇、古代骈文 2 篇、英语文学与法语文学各 1 篇。此批文本没有私人笔记、图片、译文、注释或赏析；未复制参考网站的图片、品牌或现代赏析。

源文件以 `## 篇名` 分篇。篇尾的署名逐字保留；《原毁》、Gettysburg Address、La Marseillaise 的源文件未标作者与时代，页面明确保留这一缺失。语言来自实际正文；分类沿用文件名，不按猜测增加主题、朝代或作者。源文标点、分段、诗词换行及曲牌保留；不要将录入差异悄悄校正为别的版本。

`anthology/catalog.json` 明确列出公开源文件、分类、语言、篇名及稳定 slug。`sha256_lf` 对源字节只做 CRLF → LF 规范化后计算，以适应 Windows/Linux Git 检出。任何正文更新都必须先审阅再更新哈希。普通构建只读取仓库公开副本，完全不依赖外部个人资料目录。

新增或更新时先逐篇核对来源、署名和公开范围。个人笔记、现代译文或赏析的许可不清时，先排除，不默认公开。获准附带的注释等可使用篇内 `### 注释`、`### 译文`、`### 赏析` 标题；构建保留已有正文及章节入口，不自动生成解释。无内容时不渲染空的译注栏目。

## 界面与构建

`scripts/anthology_pages.py` 验证明确清单并生成目录和详情；`home/anthology.template.html` 使用本站米色、墨绿及深色主题。`home/assets/anthology.css` 负责正文卡片、辅助栏与手机单栏。`home/assets/anthology.js` 只在本地执行全文搜索、分类与语言筛选；重置后恢复完整目录，查询写入 URL。详情的返回链接保留来时筛选与选中的篇目锚点。没有 JavaScript 时完整目录与所有原文仍可读。

`scripts/build_site.py` 将文选路由加入主 sitemap，原有 canonical、站内链接、锚点与输出边界检查继续覆盖新增页面。英文导航指向同一个文选入口并说明原文语言；不生成古文译本，不加入现有 117 篇译文。

```powershell
python scripts/test_anthology_pages.py
python scripts/build_site.py --site-url https://xieyuqing.me
python scripts/check_site.py --site-url https://xieyuqing.me --require-complete-translations
python scripts/preview_site.py
```

本地预览：`http://127.0.0.1:8767/anthology/`。每次修改还要运行 `.github/workflows/pages.yml` 列出的全部本地检查；无真实 Linux 环境时，CRLF/LF 哈希与解析测试不能称为 Linux 验证。人工检查桌面与手机、浅色与深色、搜索、分类/语言组合、空结果与重置、详情返回、长文尾段和外语换行。只修改源码，不直接改生成 HTML；不自动提交或发布。

## 划词与标记注释

划词菜单严格只有「复制」与「搜索」两个动作。搜索按钮明确标为 Google 外部搜索，在读者主动点击后打开新页；只编码所选文字作为 q 参数，不添加上下文或文章信息，使用 noopener / noreferrer。点击前不请求或预取第三方。按 Tab 可进入已出现的菜单，Escape、取消选择、点击其他正文、滚动或切页关闭。

已移除标题作者信息之后的整个常驻折叠查询框，没有挪到文末，也没有保留输入框、查询按钮或空白占位。没有未收录解释浮层。

只有已核对的词句按其本篇语境添加淡色虚线标记；点击、轻触或键盘聚焦可查看简释和参考来源，Enter/空格可进入注释浮层，Escape 关闭并返回标记。拖选或双击选词不会触发空注释。浮层内容独立于原文，标记前后正文可见文字逐字一致，仍可选择复制。
