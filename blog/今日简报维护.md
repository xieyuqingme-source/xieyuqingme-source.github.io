# 今天页维护

当前独立页面为「今天」`/today/`，英文 Today `/en/today/`，路径保留。页首显示按北京时间计算的纯日期标题「年月日」，下方依次为地球 → 地图选点天气 → 历史上的今天 → 每日阅读 → 重点新闻。静态细线与单个圆点连接过去、今天和未来，保留三个文字标签，不再显示波纹、刻度或重复日期。首页保持五块，「今天」轻量入口只显示日期、节气与小地球，不请求天气；首页浏览器标签为「谢雨卿个人网站」，英文为「Xie Yuqing’s personal website」，不改变左上品牌。

## 自动新闻

固定五家来源：中新网国内、BBC World、联合国中文、Guardian Business、NASA News Releases。接入均经过真实读取测试；保留原标题、官方来源、语种、原文链接和原始发布时间。只显示标题，不生成摘要或机器翻译。每源、每媒体最多2条，总计最多8条，按来源栏目顺序与类别轮取。

这套规则是来源栏目选题与预设规则的组合，不是独立记者选稿，也不是全网重要性评分。严格按规范链接和规范标题去重；它不保证识别所有跨媒体改写的同一事件。不能因出现“大选”“加息”等词就给新闻加“重大”标签。后续增强应先有可核对的选题依据。

`published` 是原文发布时间，`collected_at` 是本站实际成功采集时间，二者不得混用。普通条目超过72小时退出显示；来源失效或没有合格条目时，可以少收或显示新闻源入口，不凑数、不刷新旧日期。

原始查询参数保留在读者跳转链接中。去重键仅忽略明确的跟踪参数，不可盲删 `id`、`dep` 等真正决定文章的参数。只允许各来源已配置的公开 HTTPS 域名；HTML在解析时转纯文本。采集器不抓文章全文，不在浏览器直接请求第三方新闻接口。

### 调度与持久化

- 北京时间08:20、14:20、20:20运行独立采集工作流。
- 采集成功后，以带时间及内容哈希的附件保存在固定 `news-data` GitHub Release；保留最近30份。
- 先上传并确认新附件，再清理旧附件；不覆盖唯一备份，不产生每天更新新闻的主分支源码提交。
- 采集工作流成功完成后，通过 `workflow_run` 触发现有 Pages 构建。
- 正常发布只在限时内读最后有效 Release 快照，不现场访问五家媒体。失败使用已校验种子，新闻过旧时显示来源入口，文章和照片仍可发布。
- `NEWS_SNAPSHOT_PATH` 可指向临时工作区的已校验快照；普通本地构建不联网。
- 工作流文件需存在于远程默认分支才会调度。可以在 Actions 手动运行 **Update news snapshot** 检查采集、Release 附件与后续发布；是否已启用、是否运行成功，以远程 Actions 记录为准。本机构建不执行远程存储或发布。
- GitHub定时任务可能延迟或丢失排队运行；公开仓库连续60天无活动可自动停用。不能保证 Release 附件变化算作重新激活的仓库活动。偶尔检查 Actions 状态。

## 历史上的今天

第一版每天1条，共366条。依据维基百科日期资料整理，保留事件条目、取材日期页及精确修订版本；完整资料随网站保存，访问页面不会实时请求历史API。

当前363条属于自动取材/简编及完整性检查，3条另核NASA、联合国、LIGO官方资料。**不能称为全库逐条原始史料核验。** 页面“资料说明”与来源文档明确标注此边界。中文和英文的原文或译编方式亦记在来源文档。本资料集及译编使用CC BY-SA4.0，不因此改变网站其他内容的许可。

按北京时间月日选取；2月29日有独立条目，不借邻日事件补空白。历史月日遵从所引日期页，可能涉及当地日期或历法差异。新增事实必须检查日期、事件、具体出处，发现问题先改资料再发布。来源说明可在 `/assets/history-sources.md` 下载。

默认前三条，其余放入原生“更多”展开；当前每日期只有一条，因此不会显示无效的展开控件。无JavaScript时显示注明生成日期的历史内容，不能承诺跨午夜自动变化。

## 每日阅读：红色语录与旧文一句

两者每日首句按北京时间确定；小型“换一句”按钮可随时切换，遍历当前池后再开始下一轮，避免立即重复。60秒检查只在跨日时重置，不能把读者手动换出的句子覆盖掉。中英按钮通过一次性内存交接保留两句及剩余顺序；普通离开返回重新从当日首句开始。不使用localStorage或sessionStorage保存语录偏好，不读取设备定位。

「红色语录」保留马克思、恩格斯、列宁、毛泽东各5条短引文。中文和英文分别对照 MIA（马克思主义者网）所载作品的具体正文、章节或标题核对，`url` 使用 `{"zh-CN": "中文作品链接", "en": "英文作品链接"}`；旧纯字符串链接仍兼容，但不能用中文链接冒充英文出处。英文现在直接摘录所链 MIA 英文版本，不再是本站另译；各语言保留对应版本的措辞及片段范围，不宣称逐词对应，也不将译本称为作者原稿。

不采用网传名言，不把改写冒充直接引文。`translation_note` 是双语版本与语境说明，节选应标明分句或章节标题，保留必要的限定条件。每个作品累计检查摘录边界，不能靠换网页或文集卷次重置计算。资料随本站保存，阅读和换句不自动请求 MIA；点击作品链接才访问原站。来源说明在 `/assets/quotes-sources.md`。

旧文一句仍以已公开文章为准，摘句须能在原文逐字定位，链接由构建器核验。原 `home-now.js` 已退出兼容并删除；当前页面和构建都只使用 `daily-reading.js` 管理两套轮换，避免重复计时器覆盖。

## 保留的历法、天气和地图行为

日历与历史日期统一北京时间；天气和地球使用读者主动选择的城市或地图坐标。天气地图加载本站 Natural Earth 数据，可点选、拖动、缩放，也可用方向键移动、Enter 选择；拖动不会同时选点。预设城市与搜索仍在「换个地方」中，避免常驻表单占据第一屏。任意坐标显示为地图选点，不臆造最近城市名称；取得有效天气与时区后才替换当前地点，失败保留原天气。

城市搜索把输入的城市名发送到 Open-Meteo 地名服务；地图选点把经纬度发送到其天气接口，并使用返回的时区。页面不读取设备定位，仅在浏览器保存所选城市或坐标与最近一次天气。17个预设、天气缓存、29种WMO提示、体感温度/湿度/风速/风向/海平面气压继续保留；首页轻量入口不请求天气或地名服务。

地球保留昼夜、日出日落、月相、六时钟、时间滑块和减弱动态支持。固定北京、吉隆坡、伦敦、纽约、莫斯科；自选城市不在其中时排第一，否则迪拜排第六。

`knowledge.json`、`memes.json` 和旧 `news/YYYY-MM-DD.json` 仍作为既有公开归档保留校验，本轮新版不再显示小知识或热梗卡片，也不再用人工v2文件作为实时新闻来源。不要把固定日期的样刊重新当作最新一期。发布测试验证结构与规则，不锁定某一天的新闻标题、语录或历史事实。
