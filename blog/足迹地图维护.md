# 足迹地图维护

入口 `/map/`。主标题为“地图与足迹”，副标题为“三十功名尘与土，八千里路云和月。”。默认“自然地形”底图采用本地 Natural Earth II 50m 阴影地形与水体栅格，可切换的“简洁”底图采用本地 Natural Earth 110m 陆地轮廓，两层都没有国界、行政边界或地名。点为城市或县域中心的示意坐标，不是本人精确位置，也不能用于导航。来源、版本和哈希见 `map/THIRD_PARTY_NOTICES.md`。Natural Earth 数据为公有领域，无强制署名要求，页面仍保留简洁的来源链接，图片和视频不附加界面说明小字。页面不调用在线地理编码、地图瓦片、摄像头、麦克风或屏幕录制。

自然地形保留 6144×3072 JPEG 原件（4,216,152 字节）作为兼容回退；页面优先读取同尺寸 WebP 派生（quality 90，2,888,776 字节，减少 31.48%），正常加载不会再下载 JPEG。WebP 未改变尺寸、视野或地理内容，解码失败或派生读取失败才使用原 JPEG；两者都能嵌入 SVG，再供 PNG 与视频导出。JPEG 由同一 10800×5400 原始 TIFF 缩小生成，相对旧 4096×2048 保留 1.5 倍线性采样、2.25 倍像素。它仍是小比例尺自然地貌示意，不代表新增测绘细节。RGBA 解码像素至少 72 MiB，实际总内存更高；没有采用需至少 128 MiB 像素内存的 8192 版本。浏览器 SVG 按设备 DPI 绘制；PNG 固定 1600 像素宽、视频固定 1280×960，以保持可控文件和编码开销，不随 DPR 虚增分辨率。

页面末尾联系文字为“如有问题和反馈请联系作者公众号 谢雨聊。”。

时间轴标题与说明完全相同时只显示标题一次；两者不同时直接显示完整原说明，不在网页数据中截断。详情弹窗也省略相同说明。地图下方有简短的拖动、缩放、双击和键盘提示，不改变首屏大图与工具位置。主页面保留统一导航，显式设置分享描述、品牌分享图和 SVG favicon。

## 更新与本地预览

本机忽略文件 `.map-local.json` 指向自己的 Markdown 时间表。修改时间表后，在仓库根目录运行：

```powershell
./scripts/preview_map.ps1 -BuildOnly
```

刷新 `http://127.0.0.1:8768/map/`。没有预览服务时运行 `./scripts/preview_map.ps1`；后台预览可用 `./scripts/stop_map_preview.ps1` 停止。预览仅监听本机，输出 `_site_map_preview/`，有待核对提示及 noindex。它不更新公开目录、公开数据或 Git。

新版时间表以 `时间 | 城市层级地点 | 描述 | 备注` 四列表格为准；若存在该表，下面遗留的 `footprints` JSON 不再参与读取。原文不会被更新器重写。没有这种表格的旧文档仍支持一个 `footprints` JSON 围栏，参照 `map/example.md`。

表格支持年月、年月日、年、起止区间和明确的“至今”，保留原有精度。单日记录不等同长期居住；空结束日期仍代表未知。每行多城按原顺序拆为独立记录，共享分组，说明只复制该行用户原文。“长期”标为生活基地，其余为短暂停留；不把文章或照片日期当居住起止日期。

地名只由本地字典处理；未识别或有歧义时停止并请求核对。尚未确认归属的乡镇记录保留为待核对候选；用户明确确认后可用该镇区示意点，不用州府或县城替代。坐标依据保存在本地确认配置，不包含个人精确位置。

普通构建只读取 `map/catalog.json`，不会扫描 Vault 或读取本机配置。2026-10-17 经作者明确批准，公开目录最初包含 50 段经历、36 个地点，含槟城与马六甲两段旅游；来源路径和私人核对资料仍留在仓库外。本地预览或后续修改时间表不自动授予公开许可。表格没有逐项批准列，候选的默认批准状态仍为 false。每次明确授权后，先另存一份已核对的 JSON，在副本逐项设置布尔值 `approved: true`，用 `scripts/update_map.py --source <已核对副本.json>` 生成公开白名单，再审查差异；不要为了批准发布改动原时间表或旧围栏。

## 记录格式和返回画面

必需字段仍为 `id,start,end,city,region,country,lat,lon,title,description,album,certainty`。日期为 `YYYY`、`YYYY-MM`、`YYYY-MM-DD` 或空；相册只能是本站 `/photos/相册id/`。`certainty` 为 confirmed / approximate，维护源可标 pending，后者不进入预览或公开数据。

可选字段 `stayType`（base / visit）、`groupId`（同一行多城）、`sequence`（原文顺序，0–499）、`ongoing`（明确至今）、`baseReturn`（已确认的基地返回城市）和 `returnAfter`（该行之后明确返回基地）在 JSON / Markdown 导出和恢复中保留。`ongoing: true` 要有开始日期、结束为空；两个返回标记均为布尔值，true 分别要求 base / visit。来源路径、私人注释、批准开关都不会写入网页数据。

原时间表旁的同名 `.confirmations.json` 伴随文件保存已确认的返回城市、明确的中间返程和地名坐标修正。更新器只在显式读取该表格时读取伴随配置；普通构建仍只读公开目录。按起止日期和该行城市匹配，不依赖描述文字；记录变更导致匹配不唯一或失效时会报错，避免确认静默丢失。确认原话、坐标来源和私人备注不进入网页，只输出经过白名单校验的布尔标记及已确认地点。确认经历不等于允许公开，表格的批准状态仍为 false。

视频根据长期基地的区间派生必要的返程幕，标题为“返回北京”等“返回＋城市名”，使用这次外出最后已记录的结束日期；年月或年精度原样保留，绝不补成具体某日。重叠记录采用最晚的原始结束值。原始经历、明确手动记录的返程城市、说明、日期、`returnAfter` 字段均保留；派生返程不写入经历 JSON / Markdown。

同一行多城不插入返程。前一段结束与后一段开始为同一天或紧接下一天时串联；重叠范围保守串联并提示，顺序仍按原记录，不据此证实逐日行程。连续规则优先于旧 `returnAfter` 提示，避免旧标记制造往返；明确录入的返程经历始终作为原始节点保留。只有一天未记录的空档不证明回过基地，原行仍分开，省略中间推断返程并提示；不会无差别合并缺失日期或更长间隔。用户的武汉 2 月 11–12 日→四川 2 月 13–25 日→重庆 2 月 27 日–3 月 3 日按此顺序展示，中间不回东莞。其他有明确较长间隔的外出仍分别考虑返程。

连续行程结束、结束日已知且落在唯一有效居住阶段内，才考虑自动返程；终点已是返回城市时不重复。下一段日期未知、跨居住阶段或基地日期范围冲突时保守省略。基地多城仍要求唯一 `baseReturn: true` 或显式选择，不把作者的东莞套给访客。

## 视频、图片和头像

主入口为“生成足迹视频”。开头 1.4 秒只显示底图，没有城市点、地名、头像或经历字幕；每次首次到达才解锁该城市，已经到达的点持续保留，返回同城不增加城市数。默认舒适节奏每幕至少停留 2.6 秒，移动约 1.5–2.3 秒并缓动，另有轻快、从容两档。日期、城市和用户说明同时入画；长说明按实际字宽分屏，保留全部原文并延长停留。返回幕使用独立界面标签，说明为空。开启路线后只画已走过的段和正在延伸的一段，不提前画未来路线。

浏览器 Canvas + MediaRecorder 仅录制地图画布，无声、无配乐、无上传。输出 1280×960、30fps；优先选实际支持的 WebM VP9 / VP8，浏览器仅支持 MP4 时才使用准确的 MP4 后缀。编码支持仍可能在启动或运行时失败，错误会明确显示；不支持时继续提供 PNG / SVG，建议新版 Chrome / Edge。

录制按实际时间进行，生成约三分钟视频通常也要约三分钟。保持页面在前台；隐藏、离开或取消会放弃半成品并清理资源。生成期间地图、数据、头像、节奏和主题控件暂时锁定，取消后恢复。进度完成后可预览并点击下载，不会自动保存视频。重新生成会释放旧视频；超过 30 分钟或 128 MiB 会停止，宜拆分经历或使用较快节奏。

默认“平滑跟随”采用独立视频镜头，以当前位置为中心缓动平移；长距离移动适当拉远，到达后停留读字，片尾 3.6 秒拉远到完整轨迹，再停留 2.6 秒。自然地形保持原资源与风格，不额外下载地图。历史路线降低对比度，当前段加粗；字幕为 42px 日期、60px 城市与 44px 说明，长说明按两行分页而不删减。也可选择“固定当前视角”，使用生成时的网页地图视野。地图画面优先展示，视野、缩放、底图、视频及导出工具均位于地图下方，窄屏时间轴排列在地图面板后。大图右上方始终保留退出按钮，也可按 Esc 关闭。拖动可平移，地图内滚轮以指针为锚点连续缩放，双指和按钮缩放保留；地图外滚轮正常滚动页面。中国、世界等仅是初始视野，均可继续缩小到全球可见窗口并平移到世界边缘；上限为初始倍率的 64 倍。键盘方向键平移，＋／−缩放。城市使用小点，悬停时显示名称，点击可查看各次经历；密集地点先提供选择列表。“显示城市名称”控制常驻标签，默认关闭并记住选择，拥挤或边缘处省略放不下的标签，点位不变；隐藏后仍可悬停或点按。常驻名称没有背景框，使用细轮廓保证明暗底图可读；文字不可选中，也不拦截地图手势。静态图片与视频采用同一套标签避让，视频只为已到达的城市显示名称，片头没有地名，返回同城不重复计数。“按城市查看”默认收起。录制、完成、取消和视频预览定位均不调用网页地图的帧或镜头修改接口，普通地图的视野、选择与静态导出保持原状态；PNG / SVG 仍导出当前网页地图。视频镜头不写入浏览器草稿。图片不能恢复经历数据。长说明导致 PNG 超过浏览器画布限制时，改用 SVG 保留全文。

默认使用雨聊猫经典标准图的缩小网页副本，原图不变。自定义 PNG、JPEG、WebP 最大 5 MiB，签名校验和解码后在本机重编码。头像仅本次页面会话有效，不包含在经历 JSON / Markdown、浏览器经历保存或恢复中；可单独下载处理后的头像，下次重选。

## 手机触控

内嵌地图默认让单指竖向滑动滚动页面，并保留浏览器原生双指页面缩放；点按城市仍可查看经历。手机下方“操作地图 · 展开”进入明确的地图操作视图，单指平移、双指缩放地图；不保存操作模式。桌面鼠标拖动、滚轮、双击添加与键盘方式保持原样，手机可直接点“添加经历”，不依赖双击。

大图的轻量顶部栏只保留“工具与导出”和退出入口，实际控件仍在地图下方；工具快捷入口滚动大图面板，滚到底时退出按钮仍固定可达。退出恢复进入大图时的页面滚动位置，避免固定面板从文档流移除造成页面位置跳动。触屏主要按钮和标签点按区至少 44px，表单文字 16px；弹窗与大图包含 `safe-area-inset-*` 防护。视频画布不可用时禁用生成并明确保留 SVG 退路，PNG 编码失败、无录制器或无可用编码器也保留现有图片操作。

`node scripts/test_map_mobile.cjs _site_unified .local-checks/map-mobile-after` 使用独立无持久化 Chrome、外部请求拦截和合成经历，覆盖 320/360/390/430px 竖屏及对应横屏、DPR 2–3。实际 CDP `Input.dispatchTouchEvent` 检查页面单指滚动、地图双指缩放与原生页面缩放；检查短视口表单、点按入口、标签、大图下方工具/退出、背景与退出位置、PNG/SVG 和能力降级。可用 `PLAYWRIGHT_MODULE` / `CHROME_PATH` 指定已有运行时与浏览器，`QA_FILTER` 定向重跑；`--before` 仅记录问题，不把发现的问题当作 after 通过标准。证据仅写本机忽略目录。缩短视口不等于真实软键盘；未在实体设备、iOS/Safari 或有实际显示缺口的屏幕验证安全区。

## 访客草稿

“制作你的地图”可填写、导入、编辑、导出和恢复 JSON 或带 `footprints` 围栏的 Markdown。HTML 只作为文字，不执行。相同 id 同内容跳过，冲突整次拒绝；同城多次到访保留独立 id。最多 1 MiB / 500 条。表格里的城市没有坐标确认，不会在浏览器默默猜地名或回退到旧 JSON；请逐条填写或先用本地更新器转换。

默认只在当前页面内存中；主动保存才写当前站点浏览器存储。文件和本机保存由用户管理，不会上传、注册或连接后台。页面不再提供复制个人足迹的按钮。访客工具中的“撤销”可依次退回最近 50 次添加、编辑、移除、导入、改名、恢复或清空之前的草稿；“一键清空”仅清当前访客草稿，也可撤销，不清空站长时间表或源文件。

地图空白处双击或使用“添加经历”会打开访客草稿表单，按当前平移与缩放换算坐标。请手填并确认城市、日期和说明；不根据坐标猜地名。个人模式也只会在新经历保存成功后切换到访客草稿，取消、关闭或 Esc 不改变数据。空白单击不添加，拖动、滚轮后残留双击及现有地点点击不会误触添加。移动端可使用地图下方显式“添加经历”入口。
