# 读马恩维护

「读马恩」是面向中文读者的原著阅读栏目，入口为 `/marx/`。简介固定为「原著好啊，原著得读，我也想读原著。」。中文引文以中马库的《马克思恩格斯文集》（人民出版社，2009）为准；《资本论》第一卷使用中马库据《马克思恩格斯全集》第23卷（1972）录入的文本。

第一版包括十卷书架、三卷《资本论》目录、第一卷中英章节对应、三条阅读路线、12篇核心篇目导读、20张概念卡、8张考据卡、第一卷前三章导读，以及问对录目录，共63个独立页面。第一版采用文字与CSS书脊，不使用图片；十卷书脊样式一致，不单独突出《资本论》各卷。

## 第二版本地实现（2026-10-29）

第二版在首版基础上新增44页，栏目共107页：第一卷补齐第4—25章22篇导读，现有25章均有导读入口；新增实验室及三个工具、十题一轮的小测验、按40部规范著作分组的250条共享名句、生平年表、书信盲盒、专题目录与中国专题；另增「原著一段」和「中英之间」各6张。现有解读共77篇，今日一卡使用40张已发布卡片。P6公版图片本轮未采用。

本轮仅本地实现与验证。代码、内容和文档尚未暂存、提交或发布；下述是本地版本的维护方式，不代表线上已更新。

中国专题保留指定标题，同时明确《波斯和中国》《俄国在远东的成功》的作者是恩格斯；印度两篇作为比较阅读。每篇概述100—200汉字，未额外加入原著短引。首次连载日期与写作日期分开；《中国和英国的条约》原书编者指出的条约叙述问题在概述中保留。第62封候选信目录年与正文日期有分歧，本轮不纳入盲盒，也不直接改原目录。骨灰投葬日期在所引电子年表与另一机构资料中有月数分歧，也退出本版；未擅自把另一来源日期改进文集引文。

## 入口与构建

「作品」下拉菜单依次为今天、学英语、读马恩、AI应用、小游戏；页脚及「今天」页的马克思主义名句卡片也提供入口。英文页面的入口也前往中文版 `/marx/`。本栏目不生成 `/en/marx/`，不加入双语 `FEATURES`，不计入文章、译文数量或文章RSS。

与「马克思主义名句」双向互通：名句卡片底部的「去读马恩 →」进入本栏；本栏首页简介下有「每天一句马克思主义名句，在「今天」页 →」，来源说明页有一节说明两套资料的关系，并链接今天页名句卡片（`/today/#daily-quotation-card`）和名句逐条出处（`/assets/quotes-sources.md`）。名句库另有选句规则，也收列宁、毛泽东等人，本栏只收马恩，第二版的名句归类与出处测验只读共享库内马恩记录，保留原版本和出处；读马恩短引库仍独立维护，不向共享库反写。

问对录低调处理：栏目首页、资本论总览、第一卷目录和章导读都不再列问对录，只在首页目录下方放一个「问对录」小按钮，进入 `/marx/qa/`。目录页按卷、章、节归类，显示文章日期；章节下附本章导读和中文原文链接。该页只罗列站主原有文章，不加AI辅助说明。

统一构建由 `scripts/build_site.py` 调用 `scripts/marx_engels.py` 读取和校验公开文件，再由 `scripts/marx_render.py` 生成HTML及路由。普通构建只读取仓库内明确列出的数据与正文，不联网采集、不读取私人笔记或本机研究缓存。主动点击原著链接才会前往中马库。

## 元数据约定

`catalog.json`顶层为`version`、`columns`、`cards`、`works`、`guides`。共同字段包括`slug`、`title`、`summary`、`level`、`branch`、`tags`、`citations`、`related`、`added`、`status`和`ai_assisted`。字段按明确名单校验，不能随意增加本机备注。

- `level`：1唯心主义、2形而上学、3修正主义，由浅到深。这三档是玩笑式的难度名，页面上一律写成「难度：唯心主义」这类形式，首页筛选下方和文集卷页另有说明，避免读者误以为是在评价作品立场。`branch`采用`philosophy`、`economics`、`socialism`，可以有多个。
- 卡片另有`column`，概念卡用`term`，考据卡用`verdict`；篇目导读用`work`关联文集篇目；章导读用`volume`与`chapter`。
- `citations`只保存集中引文的ID。`related`必须指向真实内容，不得让已发布内容指向草稿。
- `references`是补充依据，字段为`level`、`label`、`url`、`checked_on`。`level: 1`用于补充原著，`level: 3`用于题注、编辑说明或年表。均链接中马库中文原页，页面分别显示为「原著参考」和「题注与背景资料」。
- `sources`留给第五级延伸阅读，与上述一级、三级依据分开。补充参考不会自动成为原文引文块。
- 篇目写作年不明时`year: null`，需要时用`year_note`说明；发表年不能替代写作年。引文英文对应的所引版本年查不清时`source_year: null`，不猜测。
- 《资本论》章级`en`为数组：中文一章可以对应多个英文章，第二卷的一个逻辑章也可能分成多个英文网页。英文链接数量不等于章数；中英章号和版本说明各自保留。
- 第1—4卷目录页码为篇目或小节起始位置。`page_kind: section_start`不能写成精确引句页；第5卷引用`page`、`page_kind`均为`null`，用1972年文本的章、节定位。

问对录索引目前有11篇，包含需求线索未列出的已发表第二种价值形式文章。索引通过真实文章路径关联，原文、标题与署名继续由原文章维护。`qa`是保留路由，卡片不能用这个slug。

## 新增或修改正文

1. 在所链中文原著中核查概念、作者、作品、版本和上下文。需要背景日期时核题注或年表，分清作者正文与编者说明。
2. 在`catalog.json`登记元数据，并在对应目录写同名Markdown正文。所有新路径先检查是否与`capital`、`wenji`、`sources`等保留路由冲突。
3. 正文用本站自己的解释；引文集中登记，再按ID引用。所有超过6字的中文引号片段必须属于本页绑定引文的连续子串；省略不能改变原意，两个稿本不得拼接。
4. 填写已核的`references`或第五级`sources`，再检查关联项和各条引文的依据。
5. 构建、离线检查与浏览器验收通过后，审阅待提交差异。

正文H2按下表排列，自动区块交给渲染器，不在Markdown中重复复制。

| 类别 | 正文H2 | 汉字范围 |
| --- | --- | ---: |
| 概念卡 | 白话、例子、身世、常见误读 | 400—900 |
| 考据卡 | 流行说法、证据、结论 | 300—800 |
| 篇目导读 | 写作背景、主要观点、怎么读 | 500—1000 |
| 章导读 | 一句话、关键概念、读的时候注意、常见误读 | 600—1200 |
| 原著一段 | 导读、逐句看、可以接着读 | 300—1000 |
| 中英之间 | 对照、为什么、可以这样读 | 250—1000 |

长度按去标题和Markdown链接URL后的汉字计算。篇目导读的主要观点写3—5条；篇目、章导读原文块最多3条。原文、章节结构和英文对应由数据自动生成；问对录只在 `/marx/qa/` 汇总。

现代例子集中放在概念卡「例子」节，明确是帮助理解的类比。渲染器另统一说明例子为本站编写。43篇首版解读以及34篇新增解读的`ai_assisted`均为`true`，页尾统一显示「本站解读由 AI 辅助起草，引文逐字核对过所链原文」。目录、路线和来源说明也显示相应AI辅助说明。

## 引文、勘误与摘录量

`citations.json`每条保存`id`、`vol`、`work`、`locator`、`page`、`page_kind`、`edition`、`text`、`url`、`errata`、`checked_on`。英文对应可另填`en`，中文原文必须来自对应中文本。引文保留星号、方括号、尖括号及其他原著记号。

修改引文后，同步更新`citations-review.json`中的文字SHA、原始正文SHA、定位与核对方法；使用勘误时同时关联`errata`。这些离线指纹验证记录和文字是否一致，语义与上下文仍须人工核查。

勘误逐条记录原网页、错误片段、正确片段、中文核对依据和日期。优先使用另一份中马库中文本；明显页眉混入或识别错误须说明具体上下文。换版才能解释的差异，不得直接当作录入错误改掉。

本站编辑上限为：单条150字；单页600字且不超过解读正文的一半；每部作品累计2500字且不超过所核原著长度的十分之一；不足3000字的短作品以三分之一为比例上限；《资本论》每卷累计上限10000字，仍受比例限制。重复出现在不同页面的引文逐次累计；来源页校勘对照能归属原著的计入该作品，目录资料另计并纳入栏目总量。原著长度记录采用已核的完整源篇章或部件正文下限，不冒称整部著作总字数。构建超限会失败。

这些是本站的编辑边界，不能视为法律授权。阅读全文直接链接中马库，本站保存目录、短引文和解读。
