# 全站双语维护

## 语言与内容

网站的界面语言为简体中文和英语。中文页面保留原地址；对应英文功能页使用 `/en/` 前缀，例如 `/map/` 对应 `/en/map/`，`/game/ranking/` 对应 `/en/game/ranking/`。文章使用翻译清单中已有的稳定配对，不能通过给任意原文地址加 `/en` 猜测译文地址。

首页、关于、作品和文章的语言按钮打开对应的完整页面。相册、地图、排行和文选共用功能脚本，可在当前页面切换显示语言，保留当前页面的编辑、筛选、视图或打开的内容。浏览器后退、前进也恢复对应语言。查询参数和锚点保留。

没有中文对应译文的英文原创显示明确的“中文目录”普通入口，不把目录入口伪装成同篇译文切换，也不为它制造译文或假的 `hreflang`。

`xieyuqing-site-language` 仅记录用户主动选择的界面语言；显式访问的地址优先，不依据浏览器语言强制跳转。主题继续使用原来的 `xieyuqing-blog-theme`。已有地图草稿、排行存档和导入导出格式独立于界面语言，不以翻译后的文字覆盖用户数据。

文选的古文、英文、法文原作保持原语言；英文题目、分类、导读和简释属于展示资料。不要把导读当全文翻译，不要补猜缺少的署名、时代或出处。照片和地图的英文展示资料不得改变拍摄时间、坐标或经历事实。

## 共用结构

- `scripts/site_i18n.py` 负责生成两种语言的页面、首屏文字、配对链接及 SEO 元信息。
- `home/assets/site-i18n.js` 提供浏览器端文案查询、同页切换、历史恢复和可访问性标签更新。
- `home/locales/common.json` 管理公共导航、语言切换和主题文案。
- `home/locales/photos.json`、`map.json`、`games.json`、`anthology.json` 管理各模块的展示文案。地图公开记录的英文展示资料另存于 `map/display.en.json`。

两个语言对象应具有完全相同的键和插值占位符。新增按钮时同时补齐正文、提示、空状态、加载/成功/失败、取消和无障碍标签。模板中的 `data-i18n` 只标记纯文本节点；不要标记包住输入控件、图标或原作内容的容器。属性文案使用 `data-i18n-title`、`data-i18n-aria-label`、`data-i18n-placeholder`、`data-i18n-alt`。

动态显示使用 `SiteI18n.t(key, values)`；用 `onChange` 更新展示，不重新初始化模型或保存翻译后的草稿。导出的展示图片和视频使用生成时选定的语言；可恢复的 JSON 数据保留原始内容。导出进行中切换语言不得让同一个视频混入两套字幕，也不得破坏取消后的原视图。

新增功能路由时，在共用路径映射及生成器中加入对应关系，并补齐 `lang`、自身 canonical、互相指向的 `hreflang`、导航和站点地图。正文中的引用、外链及文章 Original 链接不能批量改写。

## 文章译文

现有译文为保存到仓库的静态英文稿，访问页面不调用翻译 API。新增或修改中文文章后，运行 `python scripts/check_translations.py` 检测缺失或过期译文；完整发布验收使用 `python scripts/check_translations.py --require-complete`。

检测命令不会自动生成译文。需要由作者或助手完成全文翻译、核对原文与引用、链接、图片和代码后，更新 `blog/translations/` 中的稿件及 manifest 配对/源内容签名。不得用占位摘要充当全文译文，也不得通过修改中文正文消除译文过期提示。源内容签名将 CRLF 与 LF 视为等价，真实文字变化仍使译文过期。

中文 URL、时间和原有评论线程保持原样；英文译文的 Original / 中文原文按钮回到具体原文。评论与浏览统计继续关联原文章身份，避免双语重复计数。

## 本地验证

完整本地命令以 `.github/workflows/pages.yml` 的 Python、Node 检查为准。新增共用语言回归为 `node scripts/test_site_i18n.cjs`，服务端帮助及目录完整性回归为 `python scripts/test_site_i18n.py`。运行 `python scripts/build_site.py --site-url https://xieyuqing.me` 构建，并执行严格链接和译文完整性检查。

真实浏览器验收使用全新临时上下文和独立测试数据，覆盖英文首页到各功能、原位切换、前进后退、未保存输入、保存恢复、导入导出、取消和重复点击。不要用作者真实存档测试清空或覆盖功能。分别检查桌面/窄屏、深浅主题和长英文文案；实际设备、系统下载或剪贴板未测时应单独注明。

生成目录、测试视频、日志、`.map-local.json`、`.photos-local.json`、依赖缓存和个人资料均不属于提交内容。发布由作者确认后另行进行。
