## 故事

在马来西亚学英语，有时会发现，一个看起来很“英语”的搭配，其实借了邻居的词。韦氏词典把 amok 连到马来语，并说明早期记录与失控的暴力行为有关。后来，副词用法的范围放宽，run amok 可以描述无法约束、到处乱来的状态。

这里的 run 不一定要译为跑步。说 rumours run amok，是谣言四处失控传播，不是谣言穿上了运动鞋。一个固定搭配的意思，不能总靠每个词分别翻译后相加得到。先认出整体，再用上下文决定程度，往往比背一条僵硬中文释义更有用。

词源故事也有边界。早期欧洲人对东南亚的描述，常把复杂行为附着在地域印象上；今天引用这个词，不该把旧叙述当作某种民族的天性。韦氏释义已经说明，相关行为并非某一文化所独有。语言知识可以让人看到历史联系，也应让人看见历史描述中的局限。理解来历，不等于接收来历中的所有成见。

## 可以这样用

- 例句（本站编写）：Without clear rules, rumours can run amok. —— 缺少明确规则，谣言就可能失控传播。
- 例句（本站编写）：The children ran amok in the empty hall. —— 孩子们在空大厅里闹翻了天。

第二句是夸张的日常描写；谈严重伤害时仍要保持措辞准确，不把不同程度的行为混成一种。
