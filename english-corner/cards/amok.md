## 故事

rumours run amok，难道是谣言穿上跑鞋了？这里的 run 和跑步没有直接关系，整个搭配是在说谣言失控蔓延。

韦氏词典把 amok 连到马来语，早期记录与失控的暴力行为有关。后来英语用法逐渐放宽，run amok 也能形容事物乱了套、四处横行。于是同一个搭配，既可能出现在严重事件的报道里，也能夸张地写孩子闹翻大厅。

程度要靠上下文判断，不能看见 amok 就把每次胡闹都译成暴力。它的历史还有另一层提醒：欧洲早期记述曾把这类行为附着在东南亚的地域印象上，但韦氏说明，相关现象并非某一种文化独有。一个借词留下了接触史，不该被拿来替一个族群下定义。

## 可以这样用

- Without clear rules, rumours can run amok. —— 缺少明确规则，谣言就可能失控传播。
- The children ran amok in the empty hall. —— 孩子们在空大厅里闹翻了天。

前一句说传播失去约束，后一句是日常夸张。run amok 的热闹程度，得看整句话。
